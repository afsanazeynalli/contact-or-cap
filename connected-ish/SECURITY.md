# Security Policy

## Reporting a vulnerability

Please do not disclose security-sensitive information in a public issue.

Use GitHub's private vulnerability reporting if it is enabled for the repository. Otherwise, contact the maintainer privately through the GitHub profile.

## Research-data security

This project is primarily a scientific data-analysis workflow. The most important practical security rule is **do not commit proprietary subsurface data or credentials**.

Never commit:

- passwords or API keys;
- proprietary well coordinates;
- confidential pressure/production histories;
- company-only interpretations;
- restricted seismic or reservoir-model files.
